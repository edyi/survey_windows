# 調査用バッチ

このリポジトリは、Windows 端末の基本情報およびネットワーク診断情報を収集し、テキストファイルとして保存するためのバッチファイル（check.bat）を提供します。

## ファイル構成
- check.bat: 情報収集と疎通確認を実施し、結果をファイルに出力します。

## 動作要件
- 対応 OS: Windows 7/8/10/11（cmd.exe）
- 必要コマンド: systeminfo, ipconfig, ping, getmac, doskey, wmic
- 権限: 一部情報取得やイベントログ抽出には管理者権限が必要な場合があります
- ネットワーク: 外部/内部宛の ping を実施します（組織のポリシーによりブロックされる場合あり）

## 使い方
1. 本リポジトリから check.bat を任意のフォルダに配置します。
2. エクスプローラーからダブルクリック、またはコマンドプロンプトで実行します。
3. 実行中は画面に「PLEASE WAIT......」が表示されます。
4. 実行が完了すると result.txt が生成され、最後に `YYYYMMDD_result.txt` へリネームされます（同一フォルダ内）。

コマンドプロンプトでの例:
```
C:\path\to> check.bat
```

生成物:
- `YYYYMMDD_result.txt`（実行した日付でリネーム済み）

## 収集される情報
以下の情報が、テキストファイルに順次追記されます。

- 実行日時（`%date% %time%`）
- ユーザー名（`%USERNAME%`）
- OS 情報（`systeminfo | findstr /C:"OS"`）
- ネットワーク構成（`ipconfig /all`）
- 疎通確認（`ping`）
  - www.yahoo.co.jp（外部疎通）
  - 8.8.8.8（Google DNS）
  - 192.168.200.254（Gateway）
  - 192.168.200.200（NAS）
  - 192.168.200.100（Printer）
- MAC アドレス一覧（`getmac /NH`）
- コマンド履歴（`doskey /h`）
- ネットワーク接続パネル起動（`control net connections`）
- システムイベントログ（当日・エラーのみの抽出: `wmic ntevent`）

## カスタマイズ方法
用途に応じて、以下を編集してください。

- 出力ファイル名/日付
  - 変数 `KEKKA`（例: `result.txt`）
  - 実行日付の結合（`%date%` を `yyyymmdd` へ整形）
  - 最終的なリネーム: `rename %KEKKA% %yyyymmdd%_%KEKKA%`
- 疎通確認先（ping 先）
  - 外部: `www.yahoo.co.jp`, `8.8.8.8`
  - 内部: `192.168.200.254`, `192.168.200.200`, `192.168.200.100`
  - 組織のネットワークに合わせて IP/ホスト名を書き換えてください
- イベントログ抽出条件
  - `wmic ntevent where "(logfile='system' and timegenerated >= '%yyyymmdd%000000.0+540' and type='error')"`
  - 抽出対象（logfile, type）や期間（タイムゾーン +540 など）を環境に合わせて調整してください

## 注意事項
- 取得結果にはユーザー名、IP アドレス、MAC アドレス等の情報が含まれます。社内規程に従って適切に取り扱ってください。
- ファイアウォールやプロキシ設定により `ping` が失敗する場合があります。単純な疎通可否の参考値として扱ってください。
- `wmic` は新しい Windows で非推奨です。将来的に PowerShell（例: `Get-WinEvent`）への置き換えを検討してください。
- `control net connections` は GUI を開くため、ログ出力はされません。

## トラブルシューティング
- `wmic` が見つからない
  - PowerShell の `Get-WinEvent` などへの置き換えをご検討ください。
- 文字化けする
  - UTF-8 対応のエディタで開く、またはコードページ設定の見直しをご検討ください。
- 権限不足と思われる
  - 管理者権限のコマンドプロンプトで再実行してください。
